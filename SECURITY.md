# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a [private security advisory](https://github.com/sakurablush/lastcall/security/advisories/new) on GitHub.

`lastcall` has zero production dependencies, which minimizes supply-chain risk.
We aim to respond to reports within 72 hours.

## Scope

Security issues in the core shutdown logic, signal handling, or timeout behavior are in scope.
Issues in example applications or third-party framework integrations should be reported
to the respective projects unless they stem from misuse of the lastcall API.
